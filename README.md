# TG 图片挑选下载器（tg-picker）

在图形界面里浏览群/频道的媒体缩略图，**喜欢哪个勾哪个，只下载选中的原图**——不用整个群聊全下，也不会像缓存提取那样把几千张图混成一坨。

- 按群/频道精确浏览，缩略图网格 + 单击选中 + 双击预览
- 支持受限保存（禁止保存）的群：走你自己的账号 API 按需下载，不依赖缓存解密
- 原始文件名优先；同名自动加 `(1)(2)`，**绝不覆盖**
- 全程跑在你自己电脑上，凭据与 session 不出本机

---

## 一、环境（已装好）

本目录下的 `.venv` 已装好 telethon + Pillow，直接用即可。

如需重装：
```cmd
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## 二、申请 api_id / api_hash（只需一次，免费）

1. 浏览器打开 https://my.telegram.org ，用你的 Telegram 手机号登录（验证码会发到你的 Telegram App 里）
2. 进入 **API development tools**
3. 随便填 App title / Short name，提交
4. 记下 **api_id**（一串数字）和 **api_hash**（32 位字符串）

> 这是 Telegram 官方给第三方客户端/脚本用的凭据，和你的登录密码无关。**不要发给任何人**。

## 三、启动

双击 **`run.cmd`**，或命令行执行：
```cmd
.venv\Scripts\python.exe tg_picker.py
```

## 四、使用步骤

**① 登录**（首次）
- 填 api_id、api_hash、手机号（带国家码，如 `+8613800000000`）
- 点「登录 / 连接」→ 验证码会发到你的 Telegram **App** 里 → 在界面上方的「验证码/密码」行输入并提交
- 若账号开了两步验证，会再让你输入一次密码
- 登录成功后凭据和 session 会保存在本目录（`config.json` / `tg_picker.session`），下次直接点登录即可，不用再收码

**② 选聊天**
- 群/频道栏填：`@用户名`、`t.me` 链接、邀请链接（`t.me/+xxxx`）、或数字 ID
- 加载数量：一次取多少个（30/60/100/200/500）
- 类型：勾「图片」就只列图片（也可勾视频/文件）
- 点「加载媒体」→ 开始扫描并生成缩略图

**③ 挑选下载**
- 单击缩略图 = 选中（变蓝打勾）；再点一次取消
- **双击缩略图** = 立刻下载这一张并自动打开（适合"看一眼就想要"的情况）
- 或者勾一批，点「**下载选中（N）**」批量下载
- 「加载更早」继续往下翻历史消息

**④ 输出**
- 默认存到本目录 `downloads\`，可在「输出目录」改（建议一个群一个文件夹，天然分开）
- 命名：优先原始文件名；没有就用 `图片_20261010_015025_12345.jpg` 这种（含消息 ID，不会重名冲突）

## 五、常见问题

**提示 FloodWait / 触发限速？**
脚本内置温和控速（每次下载间隔约 0.35 秒）并自动等待重试。下载量很大时会遇到 Telegram 限流，等一会儿再跑即可，已下载的不会重复。

**私密频道加载不了？**
需要你的账号**已经是成员**。用邀请链接时本工具会尝试自动加入；如果加不进去（需要审批等），请先在 Telegram 里加入再来。

**视频能下吗？**
能，但默认只勾了「图片」。勾上「视频」后同样可挑可下。注意大文件下载耗时较长。

**安全吗？会封号吗？**
走的是官方 API、你自己的账号，行为等同于正常使用客户端（读取+下载）。但仍建议**控制频率**，不要短时间狂拉几千条；敏感账号请自行评估。`tg_picker.session` 文件等同于你的登录凭证，**不要拷贝给别人**。

**合规提醒**：仅用于下载你自己账号有权访问的内容，请遵守所在地区法律与内容所有者的规则。本工具不做转发、不绕过服务器限制，只按需下载你本就能看到的内容。
